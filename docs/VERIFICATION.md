# 验证范围

## 标准检查

- ESLint 与 TypeScript strict 检查。
- Vitest 核心测试。
- Vite 通用生产构建及运行依赖许可输出。
- 在临时 Chrome 资料中安装真实 MV3 扩展的端到端检查。

当前测试套件包含 26 项核心测试和 17 项原生浏览器检查。发布前在干净的源码目录运行，并确认通用构建中的 `personalization.json` 没有个人条目。

## 核心行为

- 多级目录、系统根目录和受管理节点保护，禁止循环移动。
- 全局搜索覆盖名称、完整 URL、原路径、展示分类、二级组、标签；大量书签索引测试。
- 重叠虚拟映射不产生重复行，完整 URL 去重不丢查询参数和片段。
- 分类建议结构验证、歧义匹配拒绝、不确定项默认不选、应用只修改展示设置。
- 写入前备份失败则中止；部分失败后保留已完成操作的撤销记录。
- 删除恢复会重绑自己的映射；外部改动会阻止不安全的撤销。
- 递归规范化 Chrome 节点，只比较实际结构与内容，避免时间戳或字段顺序导致误判。

## 浏览器检查

工具栏打开完整标签页并复用已有 EXIT. 页面；权限仅 bookmarks / storage。首次通用安装首页为空，选择和排序可持久化，多个扩展标签页之间响应更新。

原生 API 创建、修改、移动、删除后，界面自动刷新；界面动作写回原生 API。分类页可直接管理、取消删除、确认删除和立即撤销。JSON 备份实际下载，恢复到单独文件夹并可撤销。

建议导入、预览、取消和应用均检查原生书签树不被改动。完整 URL 点击保持原样；脚本书签不可执行。深浅色随系统变化，窄屏没有横向溢出，页面没有运行时异常。

## 证据与限制

`scripts/e2e.mjs` 生成的 `artifacts/e2e-results.json` 和 `native-*.png` 使用合成测试书签。仓库展示的浅色、暗色图片来自这一测试环境。

个性化验证脚本仅用于可选本地资料；`private/`、个人截图、完整审阅稿、个人匹配文件和本地安装副本不提交到仓库。

测试验证本机原生 API，未模拟 Google 账号之间的云同步。原生书签跨设备同步由 Chrome 管理；EXIT. 展示设置目前需通过 JSON 备份迁移。

未接入在线模型、网页正文抓取或站点存活检测。Chrome 不提供事务；批量操作的原子性、删除后的原 ID 及无限历史恢复不在能力范围内。
